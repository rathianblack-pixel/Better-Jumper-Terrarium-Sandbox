# Mossy River Glade — current rework

The current game uses the all-around environment in `source/terrarium/engine/28b-miniature-worlds.js`: a winding stream, shared land/bank geometry, moss stones, ferns, fallen timber and layered rooted groves. The original `mossy` selection key is unchanged.

See the main README for running/rebuilding, the complete scene change log, and `validation/TEST_REPORT.md` for actual tests. Earlier mossy-only reports and screenshots are archived under `docs/previous-release/`; they do not validate this release.
